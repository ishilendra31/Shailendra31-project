Loops II
In the previous article, we learned about how loops work with a condition that gets evaluated to either True or False. The loop continues running as long as the condition is True.

Once it becomes False, the loop stops.

In this article, we will dive deeper into how we control loops using variables, conditions, and special statements like break and continue.

Understanding i = i + 1
In the previous article, we used the statement i = i + 1 to increment the value of i, but what exactly does this mean?

i = 0

while i < 5:

    i = i + 1

    print("Hello World")

print("Bye")

Mathematically, i = i + 1 doesn't make much sense. It is like saying 0 = 1.

But in programming, it's different.

Here’s how it works:

Evaluating the Right Side First: In i = i + 1, we first evaluate the right-hand side expression, which is i + 1. This means that the current value of i is increased by 1.

Storing the Result in the Variable: Once i + 1 is evaluated, the result is then stored back in the variable i. This essentially means that i is replaced with its new value, which is the current value of i plus 1.

For example, when the loop executes for the first time, the value of i is 0. So i = i + 1, would evaluate like, i = 0 + 1, that is, i = 1. This increases the value of i by 1 to 1.

When the loop runs for the second time, the value of i is 1. So i = i + 2, would evaluate like, i = 1 + 1, that is, i = 2. This increases the value of i by 1 to 2.

In short, i = i + 1 means increasing the value of i by 1.

Think, about it, if you want to increase the value of i by 2, then what would you write?

Defining the Purpose of a Variable
Every variable we ever define in our programs should have a purpose or significance. It’s important to always ask ourselves, what is the purpose or significance of this variable? The moment we can answer that question clearly, it helps us understand the role of the variable in the program.

For example, when we ask, "what is the purpose of the loop variable i?", we should be able to explain: The purpose of i is to keep a count of the number of times the loop runs. At any point in time, the value of i indicates how many times the loop has been executed so far.

This clarity about the purpose of a variable is crucial in making our code more understandable and manageable. It also helps avoid mistakes when we later modify or debug the code.

What Happens if We Don’t Increment i?
In loop, when we define the variable i, its purpose is to track how many times the loop has run, it helps us keep count of the number of times the loop has run. We also call it the number of iterations the loop has gone through.

If we fail to increment i in each iteration, the variable i will not be fulfilling its intended purpose. It will not maintain the count of how many times the loop has run, and will continue to be 0 all the time, indicating the loop has not run even once. As a result, when we use i later in the program to check the loop condition, we will get a wrong result.

For instance, if we want the loop to run 10 times, we put a condition i < 10, meaning continue to run the loop if the loop has run less than 10 times. The moment it has run 10 times, it will come out. But if we don't update the value of i by incrementing it at every iteration, i remains 0 indicating that the loop has run 0 times, the condition will always be true, leading to the loop running forever. We call this infinite loop. Let’s look at an example:

Example: Missing Increment of i

i = 0

while i < 5:

    print(i) # i is not incremented here, so it will keep printing 0

    print("Hello World")

print("Bye")

In this code:

We initialize i = 0, and the loop will keep running as long as i < 5.

However, since we don’t increment i inside the loop, the value of i remains 0.

This causes the condition i < 5 to always evaluate to True, and the loop keeps running continuously.

What happens here?

We violated the purpose of i, which was to track the number of times the loop has run. Since i is not being updated, it stays at 0 and doesn't help the condition change.

As a result, the loop never ends and continues indefinitely. This is what we call an infinite loop.

This shows why it's essential to follow the purpose of a variable and update it properly. When we don’t, it leads to unexpected behavior like an infinite loop, where the program keeps executing the same code forever and never moves past it.

What Happens When We Use an Incorrect Condition?
Sometimes, we might make a mistake in the loop condition, causing the loop to not work as expected.

Instead of using the loop condition as i < 5, what if we put the condition i > 5?

Example: Incorrect Condition i > 5

i = 0

while i > 5:

    i = i + 1

    print("Hello World")

print("Bye")

The condition i > 5 here says, continue to run the loop if the loop has run more than 5 times.

If we read it like this, we already know this is wrong, because we don’t want to run the loop after it has already run 5 times. We want the loop to run until it has run 5 times.

Also, since i is initialised to 0, the condition i > 5 is false right from the start.

As a result, the loop will exit and not run even once. The program will exit the loop immediately without executing any code inside the loop.

So instead of memorising the code, try to look at what is actually happening.

Using the break Statement to Exit a Loop
Sometimes, you may want to exit the loop early based on some additional condition that wasn’t planned in advance.

For example, we planned to water 10 trees, but we have to stop in the middle if we run out of water.

Example: Watering Trees and Running Out of Water

tree = 0

while tree < 10:

    print("Water the tree")

    tree = tree + 1

    if run_out_of_water:

        print("Ran out of water! Stopping the loop.")

        break

In the above example:

The loop is supposed to run 10 times (to water 10 trees).

However, if the condition run_out_of_water becomes True during any iteration, the loop is terminated early using the break statement.

This allows us to exit the loop before watering all 10 trees if the water runs out unexpectedly.

The break statement exits the loop immediately, executing the line after the loop.

Example: Using break to Exit the Loop Early

i = 0

while i < 10:

    print(i)

    i += 1

    if i == 5:  # Stop the loop when i reaches 5

        break

When We Don’t Know the Number of Iterations in Advance
In some situations, we don't know exactly how many times we need to run a loop. The condition for exiting the loop might depend on something that happens dynamically while the loop is running.

For example, we plan to water all the trees in the forest, but we don't know how many trees are there in total. That's not possible as we have limited water supply. So we continue to water trees indefinitely and will stop only when we run out of water.

Example: Watering Trees with Limited Water Supply

tree = 0

while True:  # Infinite loop until the condition is met

    print("Water the tree")

    tree = tree + 1  # Increase the number of trees watered

    if run_out_of_water:  # Condition to stop the loop

        print("Ran out of water! Stopping the loop.")

        break  # Exit the loop

In this case:

The loop starts with tree = 0, and continues indefinitely because we used while True, which creates an infinite loop.

The program keeps watering trees, increasing the tree count with each iteration (tree = tree + 1).

The loop checks the condition if run_out_of_water, which, when met, causes the break statement to be triggered, and the loop exits.

The loop will stop only when the condition of running out of water occurs, making this an example of a dynamic condition that decides when the loop should end.

This example illustrates how we can use an infinite loop (while True) when we don't know in advance how many iterations the loop will run. The loop continues running as long as the dynamic condition is not met, and we can exit the loop early by using the break statement when the condition is satisfied (in this case, when we run out of water).

Summary:
An infinite loop (while True) runs indefinitely until a specific condition (such as running out of water) is met.

The break statement is used to exit the loop once the condition occurs.

This is a powerful approach when the exact number of loop iterations is unknown ahead of time but depends on a dynamic or changing condition.

By using this structure, we can handle scenarios where we don't have a fixed number of iterations but still want the loop to run as long as some external condition is true.

Using the continue Statement to Skip an Iteration
In some situations, instead of stopping the entire loop, we may want to skip the current iteration and move to the next one. This is where the continue statement comes in. It tells the program to skip the rest of the code inside the loop for that specific iteration and move on to the next iteration of the loop.

Example: Skipping a Tree If It's Small

Let’s take the water tree example again. Imagine you are watering a garden of trees, but some trees are too small, and we don’t need to water them. We can use the continue statement to skip watering those trees and move to the next one.

tree = 0

while tree < 10:

    # Skip if the tree is too small

    if tree == 3 or tree == 7:

        print("Skipping tree as it is too small or dead.")

        tree += 1

        continue



    print("Watered tree")

    tree += 1

In this example:

The loop goes through trees 0 to 9, watering them one by one.

However, if the tree is too small (for example, if tree == 3 or tree == 7), the program skips the current iteration of the loop for that tree and moves to the next one.

The continue statement ensures that the remaining code (i.e., watering the tree) is skipped for the current iteration, and the program proceeds with the next iteration.

This allows us to skip certain conditions during the loop without breaking out of the loop entirely.

Example: Skipping Iteration When i == 5

Let’s now consider a simpler case, such as printing numbers from 1 to 10, but we want to skip printing the number 5. We can achieve this using the continue statement.

i = 1

while i <= 10:

    if i == 5:

        i += 1  # Increase the value of i before continuing

        continue  # Skip printing 5 and go to the next iteration

    print(i)

    i += 1

In this example:

We want to print numbers from 1 to 10, but we skip the number 5.

The if i == 5 condition checks if i is equal to 5. If it is, the continue statement is executed.

The continue statement skips the print(i) line when i == 5 and moves directly to the next iteration.

The loop continues with i == 6, and 5 is not printed.

Summary:
The continue statement allows us to skip the current iteration of a loop and move to the next iteration.

It’s useful when we want to avoid certain conditions but keep the loop running for the remaining iterations.

In the examples, we used continue to skip watering trees that were too small and to skip printing the number 5.

By using continue, we can control the flow of our loops and decide which iterations should be skipped without stopping the entire loop
