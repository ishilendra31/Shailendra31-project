Conditional Statements - I
Expression
We learned about arithmetic operators in the previous lesson. These operators, like + (addition), - (subtraction), * (multiplication), and / (division), help us perform mathematical operations.

When we use these operators with numbers, we create an expression.

An expression is a combination of values and operators that results in a single value.

For example:

5 + 6  # This is an expression that evaluates to 11

8 - 2  # This is an expression that evaluates to 6

4 * 3  # This is an expression that evaluates to 12

12 / 4 # This is an expression that evaluates to 3

Here, each expression uses an arithmetic operator and results in a number.

Conditional Operators
Like arithmetic operators, we have conditional operators as well.

These operators are used to compare two numbers.

For example:

10 > 5

This checks if 10 is greater than 5. It will evaluate to either True or False.

This is done using conditional operators, like:

(> (greater than))

< (less than)

== (equal to)

(>= (greater than or equal to))

≤ (less than or equal to)

These operators compare two values and check if the condition is True or False.

Conditions
A statement like 10 > 5 is also an expression. But, instead of resulting in a number, it results in either True or False.

Such expressions that use conditional operators and evaluate to either True or False are called conditions.

Decision Making
These conditions can be used to make decisions in a program.

For example, if a condition is True, the program can do one thing. If it is False, it can do something else.

Here is how it looks in code:

if condition:

    # Do something if the condition is True

else:

    # Do something else if the condition is False

This is similar to how we make decisions in real life. Here are a few examples in code format:

# Example 1

if is_raining:

    # Take an umbrella

else:

    # Go without it

# Example 2

if is_hungry:

    # Eat food

else:

    # Continue working

# Example 3

if battery_low:

    # Charge your mobile

else:

    # Continue using it

# Example 4

if homework_done:

    # Go out to play

else:

    # Stay home and finish your homework

This is how decision-making works—based on whether a condition is True or False, we decide what to do.

In the above examples, the lines starting with # represent the actions that should happen if the condition is True or False. These are not real code but symbolic examples to explain the structure of decision-making using conditions.

Note: In Python, we can add comments using the # symbol. Comments are lines that the computer ignores during execution. They are written to help us or others understand the code better.

If-Else Statements
But in programming, we have to write everything in a mathematical approach. We have to use the conditional operators.

Let's look at some examples of how we can write real conditions using the operators we know:

# Example 1

age = 18

if age >= 18:

    # Allow entry to the club

else:

    # Deny entry to the club

Here, we are using the ≥ (greater than or equal to) operator to check if the person is 18 or older. If True, we allow entry, otherwise, we deny entry.

# Example 2

marks = 75

if marks >= 50:

    print("You have passed the exam.")

else:

    print("You have failed the exam.")

Here, we check if marks are greater than or equal to 50. If True, it means the student has passed. Otherwise, they have failed.

# Example 3

temperature = 30

if temperature > 25:

    print("Switching on the fan.")

else:

    print("Keeping the fan off.")

In this example, if the temperature is greater than 25, we switch on the fan. Otherwise, we keep it off.

This is how a program decides what to do based on conditions. Using the right operator, we can build conditions to handle different situations in programming.
