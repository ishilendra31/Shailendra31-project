i=1
while i<=num:
    if i%2==0:
        print(i)
    i+=1


2.Write a program to take a number as input from the user and print all the numbers from 1 to that number, but skip the even numbers using the continue statement.

num=int(input())
i=1
while i<=num:
    if i%2==0:
        i+=1 
        continue
    print(i)
    i+=1


3.Write a program to calculate the sum of odd numbers from 1 to a user-provided number. Use continue to skip even numbers. Exit the loop when the sum exceeds 50 using a break statement.

num=int(input())
t_sum=0
i=1
while i<num:
    if i%2==0:
        i+=1 
        continue
    t_sum+=i
    if t_sum>=50:
        break
    i+=1
print(t_sum)

5.Write a program where the computer secretly picks a number between 1 and 10, and the user has to guess it. The program should keep asking the user for guesses until they guess the correct number. Use a while loop and a break statement to exit the loop once the correct number is guessed.

import random
secret_code = random.randint(1, 10)
while True:
    secret_number=int(input())
    if secret_code==secret_number:
        print("Correct guess, you win!")
        break
    else:
        print("Incorrect guess, try again")
