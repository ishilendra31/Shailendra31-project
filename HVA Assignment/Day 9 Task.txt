
1.Write a program to print numbers from 1 to a number entered by the user using a loop.

num=int(input())

i=1

while i<=num:
    print(i)
    i+=1


2.Write a program that takes a string as input from the user and prints that string after a countdown. The countdown should start from 10 and print the string once the countdown ends.

str=input()

i=10

while i>=1:
    print(i)
    i-=1

print(str)


3.Write a program to calculate the sum of numbers from 1 to a number entered by the user using a loop.

num=int(input())
sum=0
i=1
while i<=num:
    sum+=i
    i+=1
print(sum)


4.Write a program to print all even numbers from 1 to a number entered by the user using a loop.

num=int(input())
i=1
while i<=num:
    if i%2==0:
        print(i)
    i+=1


5.Write a program to calculate the factorial of a number entered by the user using a loop.

num=int(input())
factorial=1
while num>0:
    factorial*=num
    num-=1
print(factorial)
