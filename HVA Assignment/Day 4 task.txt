
1.What is the difference between a string and a number in Python? How do you print each of them?

Difference between a string and a number in Python is: A string (str) is a sequence of characters enclosed in quotes (" " or ' ').example: "Hello World" or '3110'. A number can be an integer(int) or a float point number(float).example: 10(integer) or 10.11(float).
To print a string and a number: print("Hello World") # printing a string. print(10) # printing a number. print(10.12) # printing a floating point number.

age = int(input("Enter your age: ")) # Take input as string but after using int() it converts input to an integer print(age)
height = float(input("Enter your height in meters: ")) # Take input as string but after using float() it converts converts input to a float print(height)

4.What happens when we don't use inverted commas while printing?

If we don’t use inverted commas while printing in Python, the interpreter will treat the text as a variable name instead of a string. If the variable is not defined, it will result in a NameError.
For example:
print(Hello, World!) #This will cause an error- NameError: name 'Hello' is not defined
To avoid this, we must enclose the text in inverted commas (single or double quotes), like this:
print("Hello, World!")
