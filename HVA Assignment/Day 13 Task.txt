2.Write a program to continuously accept numbers from a user, add them, and then print the sum when the user enters -1.

t_sum=0
while True:
    num=int(input())
    if num==-1:
        break
    t_sum+= num

print(t_sum)


3.Write a program to take a number N as input from the user and print numbers from 1 to N, skipping numbers that are multiples of 3.

n=int(input())
i=1
while i<=n:
    if i%3==0:
        i+=1
        continue
    print(i)
    i+=1


4.Write a program to convert a given temperature from Celsius to Fahrenheit using the formula (C * 9/5) + 32. Only accept temperatures in the range from 0°C to 100°C

c=float(input())

if c>=0 and c<=100:
    f=(c*9/5)+32
    print(f)
else:
    print("Invalid temperature")


5.Write a program to take an upper limit N as input from the user and multiply all positive even numbers up to N together, then print the product. Use a while loop in the implementation.

n=int(input())
i=1
pro=1
while i<=n:
    if i%2==0:
        pro*=i
    i+=1
print(pro)
