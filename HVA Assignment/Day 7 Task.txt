
1.If you have two conditions, when will the and operator return True?

The and operator returns True only if both conditions are True.
Truth Table for 'and' Operator
For conditions 1 and conditions 2:
(Condition 1 | Condition 2 | Result (Condition1 AND Condition2) )

( True | True | True )

( True | False | False )

( False | True | False )

( False | False | False )


2.If you have two conditions, when will the and operator return False?

The and operator returns False if at least one of the conditions is False.
Truth Table for 'and' Operator
For conditions 1 and conditions 2:
(Condition 1 | Condition 2 | Result (Condition1 AND Condition2) )

( True | True | True )

( True | False | False )

( False | True | False )

( False | False | False )


3.If you have two conditions, when will the or operator return True?

The or operator returns True if at least one condition is True.
Truth Table for 'or' Operator
For conditions 1 and conditions 2:
(Condition 1 | Condition 2 | Result (Condition1 OR Condition2) )

| True | True | True |

| True | False | True |

| False | True | True |

| False | False | False |


4.If you have two conditions, when will the or operator return False?

The or operator returns False only when both conditions are False.
Truth Table for 'or' Operator
For conditions 1 and conditions 2:
(Condition 1 | Condition 2 | Result (Condition1 OR Condition2) )

| True | True | True |

| True | False | True |

| False | True | True |

5.If a condition is initially False, what will be the result after applying the not operator?

If a condition was initially False after applying the not operator will invert it to True.

Here is the Truth Table for 'not' Operator

| Condition | Result (NOT Condition) |

| False | True |

| True | False |
